# ihuull Dark

Tema do openvscode gerado dos tokens `$dark` em `shared/ui/scss/_color-system.scss`.

```bash
node shared/vscode-theme/gen.mjs
node shared/vscode-theme/gen.mjs --check
```

Não edite `themes/ihuull-dark.json` à mão. Bake na imagem `ihuull/codespace` (Fase 51.3). O pacote contribui o walkthrough **XCODESPACES** e `extension.js` abre esse guia no first-open (no lugar do *Get Started* da Microsoft).
