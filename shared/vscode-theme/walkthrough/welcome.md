# XCODESPACES

VS Code no browser, só na VPN. Este guia substitui o *Get Started* da Microsoft.

- Tema **ihuull Dark** (tokens do painel)
- O repositório abre em `project/` — é isso que o Explorer e o Git vêem
- Cache, logs e lock do IDE ficam no HOME do container e **não** entram no commit
- Terminal, Go e Node rodam **dentro** do container, não no VPS

Para exercitar o ambiente, o repo XGIT **`teste`** tem um mini-projeto (Go + Node + `.devcontainer`). Ajuda → **Get Started** volta neste guia.
