# XCODESPACES

Ambiente **ihuull** — VS Code no browser, só na VPN.

- Tema **ihuull Dark** (tokens do painel, não o default da Microsoft)
- O repositório abre em `project/` — é isso que o Git vê
- Cache, logs e lock do IDE ficam no HOME do container e **não** entram no commit
- Terminal, Go e Node rodam **dentro** do container, não no VPS

Ajuda → **Get Started** volta neste guia.
